Exam Instructions & Guidelines

General Instructions:

  1. The countdown clock in the top right corner displays the remaining time.
  2. When the timer reaches zero, the examination ends automatically.
  3. The question palette shows the status of each question using TCS iON color codes:
    • Silver/Gray: Not visited yet.
    • Red: You have not answered the question.
    • Green: You have answered the question.
    • Violet: You have marked the question for review without answering.
    • Blue with green badge: Answered & marked for review (evaluated in GATE).
  4. For Multiple Choice Questions (MCQ), select one option. Negative marking applies.
  5. For Multiple Select Questions (MSQ), select one or more correct options. Zero negative penalty.
  6. For Numerical Answer Type (NAT), enter the value using the on-screen numeric keypad. Zero negative penalty.

📖 Complete Setup Guide: Free JSONBin.io Cloud Sync

Why use JSONBin.io? It gives you 100% free cloud storage so all your mock test scores, detailed question notes, bookmarks, and activity heatmaps are permanently saved and seamlessly synced across your phone, laptop, and college PCs without losing a single attempt.

Step 1: Create a Free JSONBin Account

  1. Visit https://jsonbin.io.
  2. Click Sign Up (you can sign up instantly with Google or GitHub).

Step 2: Copy Your Master Key (`X-Master-Key`)

  1. Once logged in, look at the left sidebar and click on API Keys.
  2. Find the row labeled Master Key (or click Create Access Key with full read/write permissions).
  3. Click the copy icon to copy your secret key (it looks like $2a$10$... or $2b$...).

Step 3: Create Your Private Bin & Copy Bin ID

  1. Click on Bins in the left sidebar, then click Create Bin (or + New Bin).
  2. In the JSON editor window, enter an empty JSON object: {}
  3. Ensure the privacy dropdown is set to Private.
  4. Give your Bin a name (e.g. cbt_progress) and click Create or Save.
  5. After saving, copy the Bin ID shown in the URL or bin details (a 24-character alphanumeric string like 6737f1a9ad19ca34f8...).
